# Лабораторная работа №0 или 1 или 01 так и не понял

Консольное приложение на Java, реализующее решение базовых алгоритмических задач.

## Структура проекта
Пакет: `edu.course.lab01`

- `Main` — точка входа, обработка аргументов командной строки.
- `FizzBuzz` — алгоритм FizzBuzz (1..100).
- `TextTasks` — реверс строки собственным алгоритмом и проверка на палиндром.
- `QuadraticEquation` — решение квадратного уравнения $ax^2 + bx + c = 0$.
- `SeriesCalculator` — вычисление суммы числового ряда.

## Сборка и запуск
1. Компиляция:
   `javac -encoding UTF-8 -d .\out (Get-ChildItem -Path .\src -Recurse -Filter *.java).FullName`
2. Запуск:
   `java -cp .\out edu.course.lab01.Main <команда> [аргументы]`
